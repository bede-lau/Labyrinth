# Labyrinth · interface reference

Everything that crosses a boundary in this repo, in one place. **If you change anything listed here,
follow §9** (decision entry + schema + both sides + tests), or `verify.sh` will fail for you.

Read order for a new agent: `status.md` → this file → `architecture.md` → `decision.md` → your `tasks/<NN>/TASK.md`.

---

## 1. The one rule

`main/` (Python backend) and `renderer/` (React/TS frontend) **never import each other.** They share
only *data*:

| Crossing | Mechanism | Contract | Enforced by |
|---|---|---|---|
| main → renderer, replay (static, $0) | `artifacts/<id>.json` fetched as `/artifacts/<id>.json` | `contracts/<id>.schema.json` | `scripts/validate_artifacts.py` (jsonschema) + `renderer/src/lib/contracts.test.ts` (ajv) + `main/tests/test_contracts.py` (schema rules) |
| main ⇄ renderer, live | HTTP `/api/*` on `127.0.0.1:8787` | `contracts/live-status.schema.json`, `contracts/live-run.schema.json` | `main/tests/test_server.py`, `test_live_gx.py`, `test_contracts.py` + `renderer/src/lib/liveContract.test.ts` (the renderer's runtime validators vs the schemas, ajv) |
| source-level coupling | **none allowed** | — | `scripts/check_boundaries.py` (`--self-test` against every known violation shape; exit 2), PostToolUse hook, `verify.sh` |

The renderer may reference outside `renderer/` only: `contracts/*.json` (type-level reference) and
`artifacts/` (data; served by vite in dev, copied into `dist/artifacts/` by the build).

## 2. Artifacts (replay data)

Generated by `cd main && python3 -m labyrinth_main.build_artifacts [--out DIR] [--only id ...]`.
Deterministic: sorted keys, floats rounded to 7 significant figures, no timestamps; `verify.sh`
rebuilds into a temp dir and requires byte equality. `artifacts/manifest.json` lists every artifact with sha256.
All have `"schemaVersion": 1`; `fetchArtifact`/`useArtifact` reject anything else.

### Shared shapes (`contracts/common.schema.json`)
- **`provenance`**: `kind` ∈ `archive | derived | prd-reported | live | rehearsal | model` (`model`, D-027: illustrative model output, parameters
  chosen for illustration, not fitted, not a W7-X simulation; drawn dashed like PRD-reported), `solverRevision`, `units`,
  `coverage{description,tStart,tEnd}`, `runtime`, `verification{outcome,details}`, `sources[]` (label,url,sha256,path).
  `verification.outcome` ∈ `passed | failed | blocked | not-applicable`. **Show it next to every number.**
- **`fixtureCheck`** (D-023): `{id, label, claimed, claimedRange?, computed, printedDecimals, matches, basis?, note?}`.
  `claimed` is the single value the PRD prints, or `null`; schema `if/then/else`: `claimedRange` `[lo, hi]` present ⇔ `claimed: null`
  (a fixture with neither is invalid). `matches` is `true | false | null` (`null` = cannot be recomputed here, `computed: null`):
  a value is compared at the PRD's printed precision, a range by `lo ≤ computed ≤ hi`, unrounded.
  `basis`: absent = `data`; `arithmetic` = only the arithmetic on PRD-reported inputs was redone (needs a computed value).
  Built only by `common.provenance.fixture()` / `range_fixture()`. **Mismatches must be displayed, never hidden.**

## 3. HTTP API (main process, live only)

`cd main && python3 -m labyrinth_main.server [--port 8787]` — stdlib `ThreadingHTTPServer` (HTTP/1.0, one request per connection), binds **127.0.0.1 only**.
Dev: vite proxies `/api` → `127.0.0.1:8787` (`renderer/vite.config.ts`). **There are no CORS headers: the frontend must use the proxy or same origin.**
Checked first on every request: `Host` not loopback (`127.0.0.1 | localhost | [::1]`, optional port) or an `Origin` present and not `http(s)://` loopback → **403**.
Only GET and POST exist: every other method (PUT, DELETE, PATCH, OPTIONS, HEAD, TRACE, CONNECT, any token) → **405** `{ok:false, reason:"method X not allowed; this API answers only GET and POST"}`
(HEAD: no body) with `Allow: GET` (GET routes, `/api/live/runs/*`, `/artifacts/*`), `POST` (launch, terminate) or `GET, POST` (unknown paths).
GET on a POST route → 405 `Allow: POST`; POST on a GET route or `/artifacts/*` → 405 `Allow: GET`; POST on `/api/live/runs/<id matching the pattern below>` → 405 `Allow: GET` (`{"ok":false,"reason":"use GET"}`); POST on any other `/api/live/runs/*`, and GET or POST on an unknown path → 404.
A connection that stops sending is dropped after `REQUEST_TIMEOUT_S` = 15 s without an answer. Error bodies are `{ok:false, reason}`.

| Method + path | Request | Response |
|---|---|---|
| `GET /api/health` | — | `200 {"ok":true,"version":"0.1.0"}` |
| `GET /api/live/status` | — | `200` live-status snapshot (`contracts/live-status.schema.json`) |
| `GET /api/live/stream` | — | SSE, `data: <live-status JSON>\n\n` every 1 s. **Max 8 concurrent streams → 503**. The renderer does not use it; it polls status |
| `GET /api/live/runs/<savedRunId>` | served only for ids matching `^(rehearsal\|live)-[0-9a-f]{12}$` (the same pattern as both contracts, D-023 item 7) | `200` saved rehearsal run (`contracts/live-run.schema.json`: exactly savedRunId, initVerified, continuationVerified, checks{init,continuation,distinctDevices,overlap}, phases[1..2] of live-status; closed at every level) · `404` if the id does not match, or the file is missing, invalid, has other keys, a false check or not exactly 2 phases |
| `POST /api/live/launch` | `Content-Type: application/json`, body ≤ 4096 bytes `{"confirmCostUsd": <number>}` equal to the current `budget.slotEstimateUsd` at two decimals, exactly (2.65 and 2.650 match $2.65; 2.6549 does not) | `202 {ok:true, reason:"Launched live-<12 hex>; $2.65 reserved as pending.", status}` · **every** refusal is `409 {ok:false, reason:"launch refused: <why>", status}` and launches nothing: Content-Type; Content-Length invalid, > 4096 or longer than the body (`body ended before its Content-Length`); not JSON (also too deeply nested); not an object; no `confirmCostUsd`; `confirmCostUsd must equal the current slot estimate $2.65 to the cent (got …)`; unavailable / not qualified (the gate's reason); guard refusal (unreconciled, over the ceiling, unusable ledger amounts); ledger locked by another process; `The ledger could not be updated (…)`; a session still running or unconfirmed; `The server is shutting down; no new sessions.` |
| `POST /api/live/terminate` | the body is never read | `200 {ok:true, reason, status}` only when every launched worker's cancel is confirmed: `Workers terminated.`, `Nothing was launched.` (the session launched no worker) or `Nothing running.` · otherwise `502 {ok:false, reason, status}` (retry it): the session's reason (danger strings below) or `Session thread still running after N s; termination unconfirmed. …`. A kill-switch-only stop is always 502. Blocks while the session thread ends its step and terminate round (≤ `join_timeout_s` = 499.5 s), then while a queued cancel settles (≤ 5 s) |
| `GET /artifacts/<file>` | path-traversal protected (encoded/double-encoded/backslash/absolute/NUL/symlink-escape → 404) | the committed artifact file |

### Shutdown (SIGINT, SIGTERM, SIGHUP)
The first stop signal runs `LabyrinthServer.shutdown` → `LiveService.shutdown`: launches are refused (409), the session is stopped and terminated, and the API
**keeps answering** (status keeps reading TERMINATE FAILED / TERMINATION PENDING) until the process exits. An unconfirmed stop is printed on stdout and stderr as
`Termination not confirmed yet — check the Modal dashboard now. <reason>` **before** anything is waited for; the wait lasts only while a cancel is queued.
Exit 0 with `Labyrinth API stopped; workers terminated.` (or `…; no worker was launched.`), else exit 2 with `…; workers NOT confirmed terminated — check Modal.`
Later signals are no-ops (the handler stays installed until exit); a signal ignored at start-up stays ignored; a closed pipe or dead terminal never changes the exit code.

### live-status `mode` ↔ UI (full mapping: the "Live state" table in `renderer/src/design/DESIGN.md` §5)
`unavailable` (no Modal credentials, `modal` not installed, **or not qualified by a recorded rehearsal**; `fallback.active` true) · `idle` (launchable; `budget.slotFits` says whether the guard approves) ·
`launching` · `live` · `fallback` (a worker failed or reported garbage, or the hard timeout hit; shown until the next launch) · `terminated` (every cancel confirmed;
once the session thread has ended the API is back at the gate's `idle`/`unavailable`, reason `Last session ended: …`).
- **LIVE may be shown only when a valid, fresh snapshot has `mode === "live"`.** `lib/liveStatus.ts#isLive` is the single source. Unreachable/invalid API ⇒ REPLAY ($0), unless a danger applies.
- **Danger** (any mode, `live`/`fallback` included; GPUs may still be billing → billing-risk pill + `Alert` on every route, never just a badge). Backend strings (`orchestrator.py`, `modal_backend.py`), matched anywhere in `reason`, any letter case; FAILED wins over PENDING:
  - `TERMINATE FAILED — check Modal dashboard; GPUs may still be billing` (kind `terminate-failed`). A reason containing `kill switch raised, stop not confirmed` (spawn failed client-side: no call to cancel, only the run kill switch raised) or `kill switch could not be set` is the same kind, marker or not.
  - `TERMINATION PENDING — cancel queued, not yet confirmed; GPUs may still be billing` (spawn still in flight; clause ends `the run kill switch is raised` or `the run kill switch could NOT be set (…)`) and `TERMINATION PENDING — terminating workers, no cancel confirmed yet; GPUs may still be billing`, which a fallback carries as `<marker>: GPU 0 (bean), GPU 1 (triangular). <cause>.` from the instant its mode is set until its terminate round's verdict (kind `termination-pending`).
  - `Stop requested; terminating workers — not confirmed yet` (mode stays `launching`/`live`; kind `stop-unconfirmed`, pill "Stop not confirmed").
  - renderer-only `connection-lost`: the API stopped answering while the last snapshot may have been billing, or a launch from this page is unresolved.
- "Terminated" wording comes from the worker records: `Other worker terminated.` / `…; workers terminated.` / `Stopped on request; workers terminated.` only when both workers were launched and cancelled;
  otherwise `Nothing was launched.`, `GPU 0 (bean) terminated; GPU 1 (triangular) never launched`, `Stopped on request; nothing was launched.`, `Session ended abnormally; nothing was launched.`
- `fallback.label`: `<Worker failed | Hard timeout reached> — playing saved GX run <id>` only while that qualified run is still served (`fallback.savedRunId` non-null); otherwise
  `<…>. No qualified GX rehearsal recorded — showing archived stella/GENE evidence`. In `unavailable`: `Live GX unavailable — playing saved GX run <id>` or the no-rehearsal text.
- Worker samples are already converted to **archive units** (t×√2, Q÷2√2) by the backend.
- **`comparison`** (D-024, optional, closed): present on every snapshot of a session, absent from the gate's snapshot with no session. The session's bean samples
  vs the archived stella and GENE traces, computed by the backend with `transport.stats` / `transport.compare` only (recomputed when the bean sample count changes).
  Top level: `tube` `"bean"`, `nSamples`, `tStart`/`tEnd` (null without samples), `marginFraction` 0.10, `method`, `saturatedClaimAllowed`, `reason`, `windows`.
  `windows` = exactly 200–300 then 300–400, or `[]` when the comparison could not be computed (`reason` says why). Each window: `window`, `covered`, `nSamples`, `mean`,
  `stderr`, `stderrApproximate` (stderr is a lower bound), `nEff`, `nEffLower` (the N_eff ≥ 20 gate's value), `stationary` (`true|false|null`, null = undecidable),
  `saturatedClaimAllowed` (the live trace's own gate on that window, as in transport `windows[]`), `detail`, `archive` = `[stella, GENE]` each
  `{code, mean, stderr, delta (live − archive), verdict: agree|disagree|inconclusive|no claim, reason}` = `compare_window` unchanged. Schema `if/then`: `covered: false` ⇒
  mean/stderr/nEff/nEffLower/stationary null and the window claim false. Top-level `saturatedClaimAllowed` is true **only** when some verdict is `agree`; consumers show a
  claim only when the flag is true **and** an `agree` verdict is present (a flag without one is an inconsistency, never a claim). **With the committed archive every verdict
  is "no claim"**: the archive's 200–300 / 300–400 windows are undecidable and their N_eff is not established, so the ≥ 20 gate is not met (D-017); the flag stays false; live means, uncertainty and deltas are still shown.
  The renderer shows it only when `isLive` (Check transport, "Live comparison").
- `budget` in the snapshot comes from the guard (D-015): `slotEstimateUsd` $2.65, `hardTimeoutS` 1500 s (less when the remaining budget is short). With `budget.json` `guardPlan`
  ($2.65 / $7.73 / $26.21) it **differs from the PRD's GPU-only $1.53/$13.73/$21.83** — show both, labelled.

## 5. Backend module interfaces (`main/labyrinth_main/`)

- **Feature → artifact:** each `features/<name>/artifact.py` exposes `ARTIFACT_ID`, `SCHEMA` (file name under `contracts/`), `build() -> dict`. `build_artifacts.FEATURES = [geometry, transport, forecast, budget, spatial]`. `--only` rebuilds a subset and keeps other manifest entries.
- **`common.io`** `dumps/write_json/sha256_file` (deterministic JSON); **`common.provenance`** `source()`, `provenance()`, `fixture(fid, label, claimed, computed, decimals, note='', *, basis=None)`
  (rounding-equality at printed decimals; raises on `claimed=None`), `range_fixture(fid, label, claimed_range, computed, decimals, note='', *, basis=None)` (claimed null, `lo ≤ computed ≤ hi` unrounded;
  raises on an empty range), `BASES`; a basis outside `data|arithmetic`, or `arithmetic` with `computed=None`, raises; **`common.paths`** pinned inputs in `data/raw/`.
- **geometry:** `vmec.py` (stella-exact radial weights, Fourier eval), `fieldline.py` (θ*=θ+λ root: Newton with bracketing/bisection fallback), `stella_reference.py` (4-sig-fig compare vs the `.geometry` file;
  `compare_out_nc()` vs the float64 `out.nc` → maxAbsErrorBmag, maxRelErrorBmag, maxAbsErrorZed, tolerance, allWithinTolerance with `FLOAT64_TOLERANCE` = 1e-10; `ceil_sig(x, sig)`; params parsed from the pinned `.in`),
  `tubes.py` (ρ 0.8 tubes, mesh, `snap()` of |v|<1e-12 → 0).
- **transport:** `archive.load_trace` (drops restart repeats; raises `DivergentRestartError` if a repeat's Q differs); `units.gx_to_archive(t, Q, identical_references=True)` (√2, 2√2; refuses unless literally `True`);
  `stats.window_mean` (∫Q dt/(b−a), linear interpolation at window edges — D-013), `window_stats(t,q,window) → WindowStats` (coverage incl. edge gaps, stderr via bias-corrected Sokal τ floored at ½ sample so N_eff ≤ N − 1 (`TAU_INT_MIN`, D-025), Student-t, half-split stationarity (se with the unfloored τ, reported N_eff capped at N − 1), `saturatedClaimAllowed` needs N_eff ≥ 20 at the τ upper bound),
  `compare.compare_window(new, archive, window, margin_fraction=0.10) → {verdict ∈ agree|disagree|inconclusive|no claim, delta, combinedStderr, margin, reason, …}` (TOST equivalence; both traces must already be in archive units).
- **budget:** `pricing.py` (single source of PRD constants, imported by the live guard), `model.py` (Decimal, half-up cents), `artifact.guard_plan()` (asks `live_gx.budget_guard.evaluate` exactly what
  `rehearse` and the service ask, in plan order, each on a reconciled ledger with every earlier allocation reserved; `budget.artifact` → `live_gx.budget_guard` → `budget.pricing`).
- **spatial:** `artifact.fixtures()` (speedup recomputed from the module's PRD means; the tally and means `computed: null`).
- **live_gx** (UNVERIFIED, UNREHEARSED — see status.md):
  - `budget_guard`: `Ledger{billed,pending,reconciled}.reserve()`, `evaluate(ledger, *, slot_min, setups, ceiling_usd, rate_usd_per_h) → GuardDecision` (`.budget_snapshot()` = the live-status `budget`;
    refuses an unreconciled ledger, billed + pending + estimate > ceiling, or amounts that are not finite non-negative numbers; never raises), `slot_estimate_usd()` ($2.65 = 6.10×25/60 + 0.10, ceil to cent),
    `rehearsal_estimate_usd()` ($7.73), `hard_timeout_s()`, `planned_call_s(kind)` (live 1500 s, rehearsal phase 2250 s), `modal_startup_timeout_s()` (300 s) / `modal_timeout_s(kind)` (= planned − 300, so billed ≤ planned).

  - `orchestrator`: `WorkerBackend` Protocol — `launch(tube, gpu_index, checkpoint) → handle`, `poll(handle) → {device_id, state, sim_time_raw, new_samples_raw, error, checkpoint?, wall_start?, wall_end?, solver_revision?}`,
    `terminate(handle)` (returns only when the stop is confirmed), optional `request_stop()`. Launch exceptions: `LaunchInFlight(message, handle, status)` = a worker MAY exist (the spawn outlived its bound — the late call is
    cancelled on arrival — or failed client-side after it may have reached Modal); the handle counts as launched. Any other launch exception = nothing was sent. Poll: `TransientBackendError` (≤ `MAX_TRANSIENT_POLLS` = 2 in a row).
    Terminate: `TerminationPending(message, subscribe)` (cancel queued), `TerminationUnconfirmed` (only the kill switch could be raised; not retried within the round), any other exception (retried with backoff).
    `Orchestrator(backend, *, hard_timeout_s, saved_run_id, checkpoints, kind, clock, monotonic, sleep, retry_sleep, terminate_backoff_s)`: `run()`, `request_stop()` (flags only, signal-safe, forwarded to

## 8. Gates (all exit 2 on failure)

`verify.sh all` stages: boundary:self-test · boundary:scan · docs:handoff · scripts:tests · main:lint (`ruff check main scripts`) · main:tests (pytest) · artifacts:schema · artifacts:fresh (byte-identical rebuild) ·
[renderer:install, only without `node_modules`] · renderer:typecheck (tsc) · renderer:tests (vitest) · renderer:build (vite). It also exits 2 when `$PYTHON` is not a working Python ≥ 3.11.
Hooks (`.claude/settings.json`): PostToolUse (Edit|Write|MultiEdit|Bash|PowerShell) → `hooks/post_edit_boundary.py` (the edited file, or the whole repo after a shell command); Stop → `hooks/stop_launcher.py` →
`stop_verify.sh` (`verify.sh all`, in WSL on Windows; skipped only on a clean tree at the last green HEAD; released after 6 blocked stops).
`check_docs.py` (D-022): a task may be `DONE` only if the last run in `tasks/<NN>/VERIFY.md` (a) ends the file with exactly `Verdict: PASS`, (b) has a `| Result |` table with a `PASS` row for every outcome ID in TASK.md, and (c) names a `commit <sha>` at which the task's owned files (backticked paths under `## Owner`) are identical to the working tree. Format: `.claude/agents/verifier.md`.
`check_boundaries.py`: the renderer side is an allow-list — every path-like token in any text file under `renderer/` (specifiers, globs, URLs, shell strings, CSS/HTML) must resolve inside `renderer/`, to `artifacts/` or to `contracts/`, and naming or running `labyrinth_main` is a violation;
the main side rejects Python imports of `renderer` and strings that name the renderer directory as a path or command target. Pure-string path logic: the same verdict under native Windows Python and WSL.
Helper scripts (D-020): `dev.sh` (toolchain PATH wrapper, caps `VITEST_MAX_WORKERS` at 4), `setup-dev.sh` (pinned, sha256-checked toolchain install), `probe-copy.sh` (isolated copy for mutation probes), `hooks/stop_launcher.py` (cross-platform Stop hook entry).

## 9. How to change an interface

1. Add a `decision.md` entry (context, decision, consequences).
2. Edit `contracts/*.schema.json` (orchestrator-owned; only change with the entry above).
3. Update the producer (`main/`), regenerate artifacts, update the consumer (`renderer/`), update this file.
4. Tests on **both** sides must change with it; `verify.sh all` must exit 0.
