# Labyrinth · interface reference

Everything that crosses a boundary in this repo, in one place. **If you change anything listed here,
follow §9** (decision entry + schema + both sides + tests), or `verify.sh` will fail for you.

Read order for a new agent: `status.md` → this file → `architecture.md` → `decision.md` → your `tasks/<NN>/TASK.md`.

---

## 1. The one rule

`main/` (Python backend) and `renderer/` (React/TS frontend) **never import each other.** They share
only *data*:

| Crossing | Mechanism | Contract | Enforced by |
|---|---|---|---|
| main → renderer, replay (static, $0) | `artifacts/<id>.json` fetched as `/artifacts/<id>.json` | `contracts/<id>.schema.json` | `scripts/validate_artifacts.py` (jsonschema) + `renderer/src/lib/contracts.test.ts` (ajv) |
| main ⇄ renderer, live | HTTP `/api/*` on `127.0.0.1:8787` | `contracts/live-status.schema.json`, `contracts/live-run.schema.json` | `main/tests/test_server.py`, `test_live_gx.py` |
| source-level coupling | **none allowed** | — | `scripts/check_boundaries.py` (self-tested against every known violation shape, exit 2), PostToolUse hook, `verify.sh` |

The renderer may reference outside `renderer/` only: `contracts/*.json` (type-level reference) and
`artifacts/` (data; served by vite in dev, copied into `dist/artifacts/` by the build).

## 2. Artifacts (replay data)

Generated by `cd main && python3 -m labyrinth_main.build_artifacts [--out DIR] [--only id ...]`.
Deterministic: sorted keys, floats rounded to 7 significant figures, no timestamps; `verify.sh`
rebuilds into a temp dir and requires byte equality. `artifacts/manifest.json` lists every artifact with sha256.
All have `"schemaVersion": 1`; `useArtifact` rejects anything else.

| id | file | schema | producer (main) | consumer (renderer) | top-level keys |
|---|---|---|---|---|---|
| geometry | 259 KB | `geometry.schema.json` | `features/geometry` | `features/geometry` | equilibrium, surface, tubes, validation, provenance |
| transport | 58 KB | `transport.schema.json` | `features/transport` | `features/transport` | units, traces, windows, triangular, reducedModalRun, unitConversion, fixtures |
| forecast | 6 KB | `forecast.schema.json` | `features/forecast` | `features/forecast` | traceId, initWindow, windowWidth, method, steps, mae, fixtures, provenance |
| budget | 8 KB | `budget.schema.json` | `features/budget` | `features/budget` | ceilingUsd, postedUsd, plannedUsd, remainingAfterPlanUsd, scenarios, fixtures |
| spatial | 1.5 KB | `spatial.schema.json` | `features/spatial` | `features/spatial` | geometry, code, nPlanes, ranks, exchanges, fieldSolve, runs, timing, independenceNote, provenance |

### Shared shapes (`contracts/common.schema.json`)
- **`provenance`**: `kind` ∈ `archive | derived | prd-reported | live | rehearsal`, `solverRevision`, `units`,
  `coverage{description,tStart,tEnd}`, `runtime`, `verification{outcome,details}`, `sources[]` (label,url,sha256,path).
  `verification.outcome` ∈ `passed | failed | blocked | not-applicable`. **Show it next to every number.**
- **`fixtureCheck`**: `{id,label,claimed,computed,printedDecimals,matches,note}`; `matches` is `true | false | null`
  (`null` = cannot be recomputed from data in this repo). Compare at the PRD's printed precision. **Mismatches must be displayed, never hidden.**

### Semantics the UI must respect (each is a past review finding)
1. **geometry `validation.acceptance129` is `blocked`** (D-007: the 129 saved stella samples are not in the repo).
   Render it from `validation.acceptance129`, never from `provenance.verification.outcome` (which now also reads `blocked`, but the schema would allow `passed`; only a backend test forbids it).
2. **geometry `surface.positions`** is `150 φ × 48 θ`, φ-major, **periodic in both indices with no duplicated seam** — wrap indices when triangulating.
   Cross-sections/boundary curves are *closed* polylines (first point repeated at the end).
3. **geometry tubes**: `tubes[0..1]` are `bean` (ζc 0°) and `triangular` (ζc 36°), 129 samples each, θ* ∈ [−π, π]; `bmag` = |B|/B_ref.
4. **transport `windows[].stationary` is `true | false | null`**; `null` = undecidable/indicative. Today **every** archive window is `null` and **`saturatedClaimAllowed` is `false` everywhere** (D-017). Show "undecidable", not "stationary", and explain why in a callout. `stderr` may be `null` (stella 200–300/300–400): show "—"; stderr flagged approximate is a lower bound.
5. **transport**: stella and GENE disagree on 1500–1893.765 (Δ ≈ −0.23). Never imply the two archive traces agree. The reduced Modal run (5.79) is `prd-reported` (nothing computed); its archive comparison values equal the computed 300–400 means; the stella 300–400 window itself is not shown stationary. Triangular 2.22 is PRD-reported, raw trace unverified, no trace emitted.
6. **forecast**: computed MAE (≈ 0.0440 / 0.0418) ≠ PRD claim (0.0444 / 0.0423): `matches:false`, verification `failed`. A sample-and-hold mean reproduces both PRD scores but breaks the 2.55 archive fixture (D-016). The persistence forecast uses a one-sided right edge and can differ from the previously revealed observation by up to ~1e-4 — never say "forecast = previous observed" literally.
7. **budget range fixtures** (14–15 d, $3,100–3,200, 28–30 d, $6,200–6,400): `claimed` is the **midpoint** of the PRD range (the PRD never printed it) and `matches` means *inside the range*. Show the range from the label/note; never render the midpoint as a PRD figure. Items with `prd-reported` provenance (GX benchmark, published stella) have `computed: null`.
8. **spatial** has no `fixtures` array (contract limitation): the 1.27× speedup is `timing.speedupRecomputed` (184.69/145.44 = 1.26987). Exchanges are listed in both directions per boundary (3↔4, 6↔1). Provenance is `prd-reported`/`blocked` (no checkpoints in repo). Label "Dommaschk geometry — not W7-X".

## 3. HTTP API (main process, live only)

`cd main && python3 -m labyrinth_main.server [--port 8787]` — stdlib `ThreadingHTTPServer`, binds **127.0.0.1 only**.
Dev: vite proxies `/api` → `127.0.0.1:8787` (`renderer/vite.config.ts`). **There are no CORS headers: the frontend must use the proxy or same origin.**
Any non-loopback `Host`/`Origin` → 403. Only GET and POST; other methods → 405.

| Method + path | Request | Response |
|---|---|---|
| `GET /api/health` | — | `200 {"ok":true,"version":"0.1.0"}` |
| `GET /api/live/status` | — | `200` live-status snapshot (`contracts/live-status.schema.json`) |
| `GET /api/live/stream` | — | SSE, `data: <live-status JSON>\n\n` about every 1 s. **Max 8 concurrent streams → 503**; prefer polling status |
| `GET /api/live/runs/<savedRunId>` | id matches `^[A-Za-z0-9_.-]{1,80}$` | `200` saved rehearsal run (`contracts/live-run.schema.json`: savedRunId, initVerified, continuationVerified, checks{init,continuation,distinctDevices,overlap}, phases[2] of live-status) · `404` if missing/invalid/not qualifying |
| `POST /api/live/launch` | `Content-Type: application/json`, body `{"confirmCostUsd": <number>}` = current `budget.slotEstimateUsd` to the cent | `202 {ok:true,reason,status}` · `409 {ok:false,reason,status}` for *any* refusal (wrong cost, bad content type/body, unavailable, unqualified, guard fails, unreconciled ledger, busy, shutting down) |
| `POST /api/live/terminate` | (body ignored) | `200 {ok:true,…}` when termination is **confirmed**; `502 {ok:false,reason:"TERMINATE FAILED…"|"TERMINATION PENDING…",status}` otherwise |
| `GET /artifacts/<file>` | path-traversal protected (encoded/double-encoded/backslash/absolute/NUL/symlink-escape → 404) | the committed artifact JSON |

### live-status `mode` ↔ UI (full table in `renderer/src/design/DESIGN.md` §5)
`unavailable` (no Modal credentials, `modal` missing, **or not qualified by a recorded rehearsal**) · `idle` (launchable) ·
`launching` · `live` · `fallback` (a worker failed or the hard timeout hit → saved evidence plays, labelled) · `terminated`.
- **LIVE may be shown only when `mode === "live"`.** Unreachable API ⇒ REPLAY ($0). `lib/liveStatus.ts#isLive` is the single source.
- `reason` can contain **`TERMINATE FAILED`** or **`TERMINATION PENDING`** even while `mode` is `live`/`fallback`: GPUs may still be billing → show as a loud danger alert, not just a badge.
- `fallback.label` says "playing saved GX run <id>" **only** when a qualified saved run exists (`fallback.savedRunId` non-null); otherwise "No qualified GX rehearsal recorded — showing archived stella/GENE evidence".
- Worker samples are already converted to **archive units** (t×√2, Q÷2√2) by the backend.
- Budget numbers in the snapshot (slot estimate $2.65, hard timeout 1500 s, rehearsal $7.73) come from the guard (D-015) and **differ from the PRD's GPU-only $1.53/$13.73** — show both, labelled.

## 4. Renderer-side interfaces

**Data access (only these):** `renderer/src/lib/artifacts.ts` — `useArtifact<T>(id)` → `{status:'loading'} | {status:'error',file,message} | {status:'ready',data}` (never blank), `fetchArtifact`, `artifactUrl(id)` = `/artifacts/<id>.json`.
`renderer/src/lib/liveStatus.ts` — `useLiveStatus(intervalMs=2000)` → `connecting | unreachable | ready`, `fetchLiveStatus`, `isLive`, types `LiveStatus/LiveWorker`.

**Routes** (`renderer/src/shell/routes.ts`): hash routes `#/locate`, `#/advance`, `#/transport`, `#/forecast`, `#/spatial`, `#/budget`;
`#gallery` (design-system review page) is handled in `main.tsx`, not a route.

**Feature views** (one folder each under `renderer/src/features/`, export names fixed so the shell can wire them):
`geometry/GeometryView`, `live-gx/LiveView`, `transport/TransportView`, `forecast/ForecastView`, `spatial/SpatialView`, `budget/BudgetView`.
WebGL/Plotly sit behind thin adapters (`FluxScene.tsx`, `PlotlyChart.tsx`) that lazy-import `plotly.js-dist-min` / `three`; jsdom tests cover the data→props logic in each folder's `model.ts`.

**Design system** — import only from `renderer/src/design` (`index.ts`): tokens (`tokens.ts` is the *only* place colour values are written; `tokens.css` is **generated**: `npm --prefix renderer run tokens`, a test fails on any byte drift),
`plotTheme`, `sceneTheme`, `format`, `status` (12 status kinds), primitives `Panel, Stat, StatusPill, ProvenanceBadge, FixtureCheck, SegmentedControl, Callout, Icon, Unit`. No hex/rgb literals outside tokens (scanned by test).

**Build/dev** (`renderer/vite.config.ts`): dev middleware serves `/artifacts/*` from `../artifacts`; `/api` proxied to `:8787`;
`closeBundle` copies `artifacts/` into `dist/artifacts/` so a static build replays with no backend (`shell/build.test.ts`).

## 5. Backend module interfaces (`main/labyrinth_main/`)

- **Feature → artifact:** each `features/<name>/artifact.py` exposes `ARTIFACT_ID`, `SCHEMA` (file name under `contracts/`), `build() -> dict`. `build_artifacts.FEATURES = [geometry, transport, forecast, budget, spatial]`. `--only` rebuilds a subset and keeps other manifest entries.
- **`common.io`** `dumps/write_json/sha256_file` (deterministic JSON); **`common.provenance`** `source()`, `provenance()`, `fixture()` (rounding-equality at printed decimals); **`common.paths`** pinned inputs in `data/raw/`.
- **geometry:** `vmec.py` (stella-exact radial weights, Fourier eval), `fieldline.py` (θ*=θ+λ root: Newton with bracketing/bisection fallback), `stella_reference.py` (4-sig-fig compare + float64 `out.nc` compare to 1e-10; params parsed from the pinned `.in`), `tubes.py` (ρ 0.8 tubes, mesh, `snap()` of |v|<1e-12 → 0).
- **transport:** `archive.load_trace` (drops restart repeats; raises `DivergentRestartError` if a repeat's Q differs); `units.gx_to_archive(t, Q, identical_references=True)` (√2, 2√2; refuses unless literally `True`);
  `stats.window_mean` (∫Q dt/(b−a), linear interpolation at window edges — D-013), `window_stats(t,q,window) → WindowStats` (coverage incl. edge gaps, stderr via bias-corrected Sokal τ, Student-t, half-split stationarity, `saturatedClaimAllowed` needs N_eff ≥ 20),
  `compare.compare_window(new, archive, window, margin_fraction=0.10) → {verdict ∈ agree|disagree|inconclusive|no claim, delta, combinedStderr, margin, reason, …}` (TOST equivalence; both traces must already be in archive units).
- **budget:** `pricing.py` (single source of PRD constants, imported by the live guard), `model.py` (Decimal, half-up cents).
- **live_gx** (UNVERIFIED — see status.md):
  - `budget_guard`: `Ledger{billed,pending,reconciled}`, `evaluate()`, `slot_estimate_usd()` ($2.65 = 6.10×25/60 + 0.10, ceil to cent), `rehearsal_estimate_usd()` ($7.73), `modal_timeout_s(kind)` / `modal_startup_timeout_s()` (startup 300 s + execution = planned, so billed ≤ planned).
  - `orchestrator`: `WorkerBackend` Protocol — `launch(tube, gpu_index, checkpoint) → handle`, `poll(handle) → {device_id, state, sim_time_raw, new_samples_raw, checkpoint, error}`, `terminate(handle)`. Exceptions: `TransientBackendError` (≤2 consecutive tolerated), `LaunchInFlight(handle)` (spawn exceeded the bound — the late call is cancelled on arrival), `TerminationPending(subscribe)` (cancel queued, unconfirmed). `Orchestrator.run/terminate_all/wait_terminated/termination_confirmed/snapshot`. **Termination is never reported confirmed until a cancel succeeded.**
  - `service.LiveService`: `status()`, `launch(confirm_cost_usd)`, `terminate()`, `shutdown()` (waits `WORST_CASE_STOP_S`+10 s; server exits 2 if unconfirmed), `saved_run(id)`. State dir `$LABYRINTH_STATE_DIR` (default `~/.labyrinth`): `ledger.json` (human-reconciled before EACH allocation; O_EXCL lock), `qualification.json`, `runs/<id>.json`.
  - `modal_backend` (only module importing `modal`, lazily) · `modal_app` (Modal App, two functions `gx_worker_live` / `gx_worker_rehearsal`, A100-40GB, `retries=0`, caps = guard timeouts; never imported by tests/server/replay) · `gx_input` (GX TOML for both tubes) · `fake_backend` (tests only, `FAKE-` device ids, not selectable by the server) · `rehearse` CLI.
- **server:** `app.make_server`, `__main__.main(argv, *, service=...)` (the `service=` hook is test-only; the CLI cannot select a fake).

## 8. Gates (all exit 2 on failure)

`verify.sh` stages: boundary self-test + scan · docs handoff · scripts tests · ruff · pytest · artifact schema · artifact freshness (byte-identical rebuild) · tsc · vitest · vite build.
`check_docs.py` (D-022): a task may be `DONE` only if the last run in `tasks/<NN>/VERIFY.md` (a) ends the file with exactly `Verdict: PASS`, (b) has a `| Result |` table with a `PASS` row for every outcome ID in TASK.md, and (c) names a `commit <sha>` at which the task's owned files (backticked paths under `## Owner`) are identical to the working tree. Format: `.claude/agents/verifier.md`.
`check_boundaries.py` is an allow-list (wave 2): any path, glob, URL or shell string in one tree that resolves into the other is a violation unless it is `contracts/*.json` or documented `artifacts/` data access; every text file under `main/` and `renderer/` is scanned; verdicts are identical under native Windows Python and WSL.
Helper scripts (D-020): `dev.sh` (toolchain PATH wrapper), `setup-dev.sh` (pinned, sha256-checked toolchain install), `probe-copy.sh` (isolated copy for mutation probes), `hooks/stop_launcher.py` (cross-platform Stop hook entry).

## 9. How to change an interface

1. Add a `decision.md` entry (context, decision, consequences).
2. Edit `contracts/*.schema.json` (orchestrator-owned; only change with the entry above).
3. Update the producer (`main/`), regenerate artifacts, update the consumer (`renderer/`), update this file.
4. Tests on **both** sides must change with it; `verify.sh all` must exit 0.

## 10. Known interface gaps

- `spatial.schema.json` has no `fixtures` array; budget range fixtures overload `claimed` (midpoint). A `claimedRange` field would fix both — needs a decision.
- `geometry.schema.json` still *permits* `acceptance129.outcome == "passed"`; only a backend test forbids it. Tighten the schema to `const: "blocked"` until the data exists.
- `live-run.schema.json` has no top-level `additionalProperties:false`; `LiveService.load_saved_run` enforces exact keys instead.
- Modal API details (`cancel(terminate_containers=True)`, `startup_timeout`, `(request, limit)` tuples, `scaledown_window`, `Image.env`, `modal.is_local()`) were written against knowledge of modal 1.x, **not an installed `modal==1.6.4`**.
